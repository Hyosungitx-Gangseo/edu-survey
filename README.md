# 교육 만족도 설문 (효성ITX 카카오뱅크 강서센터)

상담사 대상 **익명** 교육 만족도 설문과, 관리자만 볼 수 있는 결과 페이지입니다.

| 파일 | 용도 |
|---|---|
| `index.html` | 상담사용 설문 페이지 (휴대폰 최적화) |
| `admin.html` | 관리자 페이지 (로그인 · 결과 · 회차별 비교 · 설문 기간 관리) |
| `apps-script/Code.gs` | 응답 저장 서버 (구글 시트에 붙여넣는 코드) |
| `config.js` | 서버 주소와 센터명 설정 |
| `questions.js` | 문항 정의 |

## 익명성
- 이름·사번·이메일·IP를 수집하지 않으며, 제출 시각은 **날짜까지만** 저장합니다.
- 관리자 화면과 CSV 모두 응답 순서를 무작위로 섞어서 보여줍니다.
- 중복 제출 방지는 응답한 기기에 "제출 완료" 표시를 남기는 방식입니다. 실수로 다시 제출하는 것은 막아주지만, 다른 기기나 브라우저를 쓰면 다시 제출할 수 있습니다. 완벽히 막으려면 본인 확인이 필요해 익명성이 깨지기 때문입니다.

## 설치 (처음 한 번, 약 10분)

### 1. 구글 시트 + 서버 코드
1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. (예: `교육만족도_응답`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기의 기본 코드를 모두 지우고 `apps-script/Code.gs` 내용을 통째로 붙여넣습니다.
4. 맨 위의 `ADMIN_ID`, `ADMIN_PASSWORD` 값을 **원하는 아이디/비밀번호로** 바꾸고 저장(💾)합니다.
5. 오른쪽 위 **배포 → 새 배포** → 유형 선택(⚙️) **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르고 권한 승인 화면이 나오면 본인 계정으로 허용합니다.
   ("확인되지 않은 앱" 경고 → 고급 → 이동)
7. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> 코드를 수정한 뒤에는 **배포 → 배포 관리 → 수정(✏️) → 버전: 새 버전**으로 다시 배포해야 반영됩니다. URL은 그대로 유지됩니다.

### 2. 웹페이지 설정
1. `config.js`의 `API_URL: ''` 따옴표 안에 위 URL을 붙여넣고 커밋합니다.
2. GitHub 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**로, 이 코드가 있는 브랜치와 `/ (root)`를 선택합니다.
3. 몇 분 뒤 아래 주소로 접속됩니다.
   - 설문: `https://<GitHub 아이디>.github.io/<저장소 이름>/`
   - 관리자: `https://<GitHub 아이디>.github.io/<저장소 이름>/admin.html`

## 사용 방법
1. 관리자 페이지에 로그인 → **설문 관리**에서 시작일을 고르면 마감일이 다음 날로 자동 지정됩니다. (시작일 포함 2일)
2. 설문 링크를 상담사들에게 공유합니다. 링크는 매 회차 동일하며, 기간 외에는 "진행 중인 설문이 없습니다"라는 안내가 표시됩니다.
   - 기간이 겹치는 설문을 여러 개 만들 수 있습니다. 진행 중인 설문이 여러 개면 상담사가 목록에서 골라 참여합니다.
   - 특정 설문만 보내려면 설문 목록의 **전용 링크 복사**를 사용하세요(`...?s=설문ID`). 선택 화면 없이 그 설문이 바로 열립니다.
   - 마감일 전에 응답을 끝내려면 설문 목록의 **지금 마감**을 누르세요. 마감일 전이면 **마감 취소**로 다시 열 수 있습니다.
3. **설문 결과** 탭에서는 영역별 평균, 아쉬웠던 점 집계, 주관식 답변, CSV 다운로드를 볼 수 있고, **회차별 비교** 탭에서는 회차마다 영역 평균이 어떻게 달라졌는지 볼 수 있습니다.

## 보고서
보고서 이미지는 관리자 페이지에서 받은 CSV로 따로 만듭니다. 양식과 생성 방법은 `tools/report/README.md`를 참고하세요.

## 보안 참고
- 아이디/비밀번호는 구글 서버(Apps Script)에서만 확인하며, 웹페이지 소스에는 들어 있지 않습니다.
- 로그인을 5번 연속 실패하면 10분간 로그인이 차단됩니다. 로그인은 6시간 동안 유지됩니다.
- 원본 응답은 본인 구글 시트에 있으니, 시트를 다른 사람에게 공유하지 마세요.

## 미리보기 / 테스트
`config.js`의 `API_URL`이 비어 있으면 **미리보기 모드**로 동작합니다. 응답은 그 기기에만 저장되며, 관리자 계정은 `preview` / `preview`입니다.

```bash
python3 -m http.server 8000   # http://localhost:8000 접속
node dev/test.js              # 서버 코드 동작 테스트
```

문항을 바꿀 때는 `questions.js`와 `apps-script/Code.gs`의 `AREAS` / `ISSUES`를 똑같이 수정하세요.
